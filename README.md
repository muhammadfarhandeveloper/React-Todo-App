# 📝 React Todo App

A modern and responsive **Todo Application** built with **React.js**, designed to provide a simple and intuitive way to manage daily tasks.

This project demonstrates practical implementation of **component-based architecture, props, state management, event handling, task filtering, search functionality, and Local Storage**. The application allows users to create, manage, search, filter, and persist their tasks directly in the browser.

## 🚀 Live Demo

**Live Application:**  
https://reacttodoapp-farhan.vercel.app/

## 📌 Features

- ✅ Add new tasks
- ✏️ Update and manage tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 🔍 Search tasks
- 🗂️ Filter tasks based on their status
- 💾 Persist tasks using Local Storage
- ⚛️ Built using React.js component-based architecture
- 🔄 Efficient state management
- 🖱️ Interactive event handling
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

## ⚙️ Getting Started

Follow the steps below to run the project locally.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/muhammadfarhandeveloper/React-Todo-App.git
```

### 2. Navigate to the Project Directory

```bash
cd React-Todo-App
```

### 3. Install Dependencies

Install all required packages using npm:

```bash
npm install
```

### 4. Start the Development Server

Run the following command:

```bash
npm run dev
```

The application will start on a local development server. Open the URL shown in your terminal, usually:

```text
http://localhost:5173/
```

## 💾 Local Storage

This application uses the browser's **Local Storage** to save todo data.

This means that your tasks remain available even after refreshing the page or closing and reopening the browser, as long as the browser's stored data has not been cleared.

## 🔎 Search & Filtering

The application provides task management features that make it easier to work with a larger list of todos.

Users can:

- Search for specific tasks.
- Filter tasks according to their completion status.
- Quickly manage their pending and completed tasks.

## 🧠 React Concepts Demonstrated

This project was developed to practice and demonstrate several important React concepts, including:

### Component-Based Architecture

The application is divided into reusable React components to keep the code organized, maintainable, and scalable.

### Props

Props are used to pass data and functionality between React components where required.

### State Management

React state is used to manage todo data and dynamically update the user interface.

### Event Handling

User interactions such as adding, deleting, completing, searching, and filtering tasks are handled through React event handlers.

### Local Storage

Browser Local Storage is integrated to persist todo data between sessions.
